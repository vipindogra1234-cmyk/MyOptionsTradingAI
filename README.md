# MyOptionsTradingAI

AI-powered Indian stock market options trading assistant.

## Purpose
To analyze the Indian stock market and help identify potential options trading opportunities.

## Features
- Nifty and Bank Nifty analysis
- Support and resistance levels
- Option chain analysis
- Call (CE) and Put (PE) analysis
- Entry, target and stop loss suggestions
- Risk and reward calculation
- Market trend analysis
- Options buying and selling strategies
- Mobile-friendly interface

## Disclaimer
This tool is for educational and analytical purposes only.
It does not guarantee profits in trading.
